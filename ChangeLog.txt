Changelog

1.4.0
- Added Find the City: a capital is named and you drop a pin on a world map, scored by how close you land
- All four modes work for it; in Recall the city is marked and you name it
- The map gets harder by shrinking the target rather than by adding options
- Bigger default window, so the map is bigger too
- Fixed the world map changing size between rounds

1.3.1
- Fixed macOS builds being reported as damaged: the app bundle is now ad-hoc signed

1.3.0
- Added Guess the Border: a country is drawn as its outline instead of its flag
- Play now asks which game first, then which mode; all four modes exist for both games
- Each game keeps its own best scores and its own learning progress
- Fixed the answer grid sitting left of centre

1.2.0
- Added recall mode: a flag is shown and you name the country from all 197
- New look: bright sky theme with tactile buttons, oversized answer feedback and progress on the menu
- Added a quit button to a run in progress

1.1.0
- Added sound effects
- Added learning and hard mode in addition to normal mode

1.0.0
- First release
